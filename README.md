# linuxTermunalExproler
терминал для linux

1. установите файл терминала в нужную папку например /home/
2. выдайте право на исполнение (chmod +x exproler.sh)
3. запустите (./exproler.sh)
4. 4 вы в проводнике

# добавление комманды exproler
1. откройте проводник
2. выберите доп опции(0)
3. выберите пумкт для для добавления команды
4. готово проводник можно запусить из из любого места место коммандой exproler
